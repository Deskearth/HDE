# HDE

Code for ICDM2021 Heterogeneous Graph Neural Network with Distance Encoding.

## How to run?

The original experiment can be launched with:

```bash
python icdm.py
```

## Graph Transformer experiment

An additional experiment that evaluates HDE on a Graph Transformer model is
provided in `graph_transformer_exp.py`:

```bash
python graph_transformer_exp.py
```
